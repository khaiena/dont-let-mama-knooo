# Don't Let Mama Knooo!

Mama is working.

Bebe is definitely not supposed to be touching the laptop.

Unfortunately, Bebe has discovered Paint.

-----------------------------------------------------------------------------------

An interactive early-2000s desktop experience built with Next.js.

Explore a secretary mother's laptop through the eyes of her curious five-year-old daughter.

## Features

- 🖥️ Early-2000s inspired desktop environment
- 📁 Interactive folders and files
- 🪟 Draggable windows
- 🎨 Functional Paint application
- 🧮 Functional Calculator
- 📝 Interactive Notes application
- 📧 Clickable emails
- 📊 Office documents and petty cash reports
- 🎵 Music library
- 📼 Downloaded cartoons and videos
- 💛 Child-like note generator for Mama



## Project Goals

This project was built for two reasons:

1. To explore Next.js through a playful personal project.
2. To recreate the feeling of being five years old and endlessly curious about the adult world.

There are no villains, mysteries, or major plot twists.

Only folders.

And the traces of a life inside them.



## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
